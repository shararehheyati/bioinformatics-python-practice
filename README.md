# bioinformatics-python-practice
A collection of Python scripts and practical exercises for solving basic bioinformatics problems.

This repository provides simple, reusable code examples to help learners explore Python programming through biological sequence analysis.

Projects

1. DNA Base Counter
A beginner Python script that counts the number of A, C, G, and T bases in a DNA sequence.
.Concepts practiced:
.User input
.Strings and uppercase conversion
.For loops
.If/elif conditions
.Counters
